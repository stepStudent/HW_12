# Завдання 3: Expense Tracker Pro — Статистика та аналітика витрат

Розширений вебзастосунок для обліку особистих фінансів із детальною аналітикою за категоріями, пошуком у реальному часі, фільтрацією та безпечним очищенням даних. Реалізовано на чистому **HTML5**, **Bootstrap 5**, **CSS3** та **JavaScript (ES6+)** без використання React, серверних технологій або баз даних.

---

## 🚀 Реалізований функціонал (Розширення Task 1)

1. **Відображення суми витрат окремо для кожної категорії**:
   - Інформативна панель статистики на 5 карток:
     - **Загальна сума** та загальна кількість витрат.
     - **Їжа**: сума, кількість записів та відсоток від загального бюджету.
     - **Транспорт, пальне**: сума, кількість записів та відсоток.
     - **Покупки**: сума, кількість записів та відсоток.
     - **Інше**: сума, кількість записів та відсоток.
   - Усі суми та відсотки автоматично перераховуються при будь-яких змінах (додаванні, видаленні або очищенні).

2. **Пошук витрат за назвою в реальному часі**:
   - Поле швидкого пошуку (`input`) миттєво фільтрує картки витрат при введенні тексту без перезавантаження.
   - Знайдені збіги в назвах підсвічуються жовтим маркером (`<mark>`).
   - Додано кнопку швидкого очищення пошуку (`x`).

3. **Фільтрація за категоріями**:
   - Зручні інтерактивні кнопки-фільтри: **Всі**, **Їжа**, **Транспорт, пальне**, **Покупки**, **Інше**.
   - Кожна кнопка містить динамічний бейдж із поточною кількістю витрат у цій категорії.
   - Фільтр за категорією гармонійно поєднується з текстовим пошуком (знаходить витрати, що відповідають і обраній категорії, і пошуковому запиту).

4. **Кнопка «Очистити всі витрати» з підтвердженням**:
   - Додано кнопку в шапці застосунку.
   - Перед видаленням з'являється модальне діалогове вікно **Bootstrap Modal** із попередженням про незворотність дії.
   - При підтвердженні всі дані безпечно видаляються з масиву та `LocalStorage`, а статистика та інтерфейс скидаються до нуля.

5. **Збереження всіх змін у LocalStorage**:
   - Усі операції (додавання, видалення однієї витрати, повне очищення) негайно синхронізуються з локальним сховищем браузера (`localStorage`).

6. **Базовий функціонал (з першого завдання)**:
   - Форма додавання: *Назва*, *Сума*, *Категорія*.
   - Клієнтська валідація: назва не може бути порожньою, сума повинна бути `> 0`, категорія обов'язкова для вибору.
   - Видалення окремих записів із плавною анімацією.
   - Захист від XSS-ін'єкцій (безпечне екранування тексту).

## 🛠 Стек технологій

- **HTML5** — семантична розмітка.
