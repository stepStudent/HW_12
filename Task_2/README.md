# Завдання 2: Форма реєстрації з перевіркою даних

Вебзастосунок з інтерактивною формою реєстрації користувача та повноцінною клієнтською валідацією, розроблений на чистому **HTML5**, **Bootstrap 5**, **CSS3** та **JavaScript (ES6+)** без використання сторонніх серверів, баз даних або React.

---

## 🚀 Реалізовані можливості та правила валідації

1. **Поля форми**:
   - **Ім'я користувача**:
     - Обов'язкове поле.
     - Перевірка: містить мінімум **3 символи**.
   - **Email**:
     - Обов'язкове поле.
     - Перевірка: коректний формат електронної пошти через регулярний вираз (`name@example.com`).
   - **Пароль**:
     - Обов'язкове поле.
     - Перевірка: містить мінімум **8 символів**.
     - Додано кнопку з іконкою «ока» для показу/приховування введеного пароля.
   - **Підтвердження пароля**:
     - Обов'язкове поле.
     - Перевірка: паролі повинні суворо **збігатися**.
     - Додано кнопку показу/приховування пароля.
   - **Checkbox «Погоджуюсь з умовами»**:
     - Обов'язкова відмітка для надсилання форми. Без погодження з умовами відправка блокується.

2. **Відображення помилок**:
   - Повідомлення про помилки відображаються безпосередньо **під відповідними полями** (`.invalid-feedback`).
   - При некоректному введенні поле отримує червону рамку (`is-invalid`).
   - При коректному заповненні поле підсвічується зеленим (`is-valid`).
   - Реалізовано як живу валідацію під час введення (`input` / `blur`), так і фінальну перевірку при спробі відправки форми.

3. **Успішна реєстрація**:
   - При успішному проходженні всіх перевірок форму не перезавантажує сторінку (`event.preventDefault()`).
   - Відображається чітке повідомлення: **«Реєстрація успішна!»** разом з іменем зареєстрованого користувача.
   - Форма автоматично очищається.
   - Паролі **не зберігаються** у `LocalStorage` чи будь-яких інших сховищах (безпека даних).
   - Присутня кнопка «Зареєструвати ще один акаунт» для зручного повторного тестування.

## 🛠 Стек технологій

- **HTML5** — розмітка та форми.
- **Bootstrap 5.3 & Bootstrap Icons** — адаптивна сітка, стилізація та іконки.
- **CSS3** — кастомні градієнти, тіні та анімації.
- **JavaScript (Vanilla ES6+)** — регулярні вирази, обробка подій `submit`/`input`/`blur`, маніпуляція DOM.
