# Трекер особистих витрат — Expense Tracker

Вебзастосунок для зручного щоденного обліку витрат, створений за допомогою чистого **HTML5**, **Bootstrap 5**, **CSS3** та **JavaScript (ES6+)** без використання сторонніх серверних технологій, баз даних або React.

---

## 🚀 Реалізований функціонал

1. **Форма додавання витрати**:
   - Поле **«Назва витрати»** (текст, обов'язкове).
   - Поле **«Сума»** (число, обов'язкове).
   - Поле **«Категорія»** (випадаючий список із категоріями: *Їжа*, *Транспорт, пальне*, *Покупки*, *Інше*).
   - Кнопка **«Додати витрату»**.

2. **Валідація форми**:
   - Перевірка, що назва не є порожньою (і не складається лише з пробілів).
   - Перевірка, що сума є числом і суворо більша за 0 (`> 0`).
   - Перевірка вибору обов'язкової категорії.
   - Візуальне підсвічування помилок за допомогою класів `is-invalid` та інформативних повідомлень.

3. **Відображення витрат у вигляді карток**:
   - Кожна картка містить назву витрати, бейдж категорії з відповідним кольором та іконкою, дату/час додавання, суму та кнопку видалення.
   - Нові витрати додаються на початок списку.
   - Екранування HTML-символів (захист від XSS-ін'єкцій).

4. **Видалення витрат**:
   - Можливість видалення будь-якого окремого запису за допомогою кнопки-смітника з плавною анімацією.

5. **Автоматичне обчислення загальної суми**:
   - Інформативна картка з градієнтом, що показує актуальну сумарну вартість усіх витрат у гривнях (`₴`) та кількість записів.
   - Сума автоматично перераховується при додаванні або видаленні витрати.

6. **Збереження даних у LocalStorage**:
   - Усі витрати зберігаються в локальному сховищі браузера (`localStorage`).
   - Дані залишаються доступними після перезавантаження сторінки або закриття браузера.

7. **Додаткові покращення**:
   - Швидка фільтрація списку за категорією.
   - Адаптивний та сучасний дизайн (підходить для мобільних пристроїв, планшетів і комп'ютерів).
   - Плавні анімації появи та видалення карток.

## 🛠 Технології

- **HTML5** — семантична структура.
- **Bootstrap 5.3 & Bootstrap Icons** — адаптивна сітка та сучасні іконки.
- **CSS3** — кастомні стилі, плавні переходи та анімації.
- **JavaScript (Vanilla ES6+)** — робота з DOM, LocalStorage, обробка подій.

## 💻 Як запустити

1. Відкрийте файл `index.html` у будь-якому сучасному веббраузері (Google Chrome, Firefox, Safari, Edge):
   - Можна просто двічі клікнути по файлу `index.html`.
   - Або використати розширення на зразок **Live Server** у VS Code.
2. Жодних встановлень бібліотек, серверів чи `npm install` не потрібно!
